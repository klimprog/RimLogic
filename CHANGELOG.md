# Changelog

## 1.0.2

### Added
- Waypoints for manually routing signal-link lines.

### Fixed
- Signal-link lines now route more cleanly: they no longer fold back into themselves, and when needed they make a loop or detour.

## 1.0.1

### Added
- Descriptions for all blocks.

### Fixed
- English translations are now applied to block type names and descriptions.
- The mod description now appears in the current game language.
- Switching languages in-game no longer breaks mod visuals such as textures, icons, and links.
- The selector now works correctly: it is always connected to one output and switches by signal.
- Small UI and balance tweaks.

## 1.0

### Added
- Initial release: electro-logic blocks (logic gates, sensors, generators, register, timer, memory, screen, clock, loudspeaker, diode, math block, multitool), signal links between blocks with map overlays, and power-grid interaction.
