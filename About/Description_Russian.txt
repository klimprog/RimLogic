RimLogic
Электро-логические блоки для тех, кто любит, когда база думает сама

Общее описание:
RimLogic добавляет в RimWorld систему электро-логических блоков для автоматизации вашей колонии. Это мод для тех случаев, когда хочется не просто вручную щёлкать выключатели, а собрать понятную схему: датчик видит событие, логика обрабатывает условие, а нужный блок включает питание, меняет состояние, показывает число или отправляет уведомление.

В моде есть сигнальные связи между блоками, обычная работа с электросетью, датчики, логические блоки, таймеры, память, генераторы, экраны, рупор и отдельные функциональные блоки. Связи можно увидеть прямо на карте: цветные линии показывают, какие элементы соединены и куда идёт сигнал. Это сильно помогает, когда схема становится больше пары блоков.

А с помощью диода можно сделать чтобы питание шло только в одну сторону. Больше не нужно городить странные цепочки из переключателей там, где нужен простой односторонний проход тока. Диод делает такие схемы понятнее и чище.

У каждого блока есть своё меню настроек.



Требуется Harmony. Можно добавлять в существующее сохранение.
