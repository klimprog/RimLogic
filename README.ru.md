# RimLogic

*[English version](README.md)*

![RimLogic](About/Preview_ru.png)

**Электро-логические блоки для тех, кто любит, когда база думает сама.**

`Version 1.1.6` · `RimWorld 1.6` · requires [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) · [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3750951495)

## Общее описание

RimLogic добавляет в RimWorld систему электро-логических блоков для автоматизации вашей колонии. Это мод для тех случаев, когда хочется не просто вручную щёлкать выключатели, а собрать понятную схему: датчик видит событие, логика обрабатывает условие, а нужный блок включает питание, меняет состояние, показывает число или отправляет уведомление.

В моде есть сигнальные связи между блоками, обычная работа с электросетью, датчики, логические блоки, таймеры, память, генераторы, экраны, рупор и отдельные функциональные блоки. Связи можно увидеть прямо на карте: цветные линии показывают, какие элементы соединены и куда идёт сигнал. Это особенно полезно, когда схема становится больше пары блоков.

А с помощью диода можно сделать так, чтобы питание шло только в одну сторону. Больше не нужно городить странные цепочки из переключателей там, где нужен простой односторонний проход тока. Диод делает такие схемы понятнее и чище.

Соседним блокам провода не нужны: если поставить их вплотную так, чтобы выход одного смотрел на вход другого, сигнал пойдёт напрямую. Целую схему можно собрать простой цепочкой, не протянув ни одной линии.

У каждого блока есть своё меню настроек.

## Блоки и назначение

### Датчики

- **Датчик света** — реагирует на уровень освещённости.
- **Датчик движения** — обнаруживает выбранные типы существ в области: колонистов, животных, врагов, пленников и т.д.
- **Датчик температуры** — проверяет температуру по заданному условию.
- **Датчик тока** — следит за свободной энергией в сети или зарядом аккумуляторов.
- **Датчик загрязнений** — реагирует на загрязнение в области.
- **Датчик огня** — срабатывает, если рядом есть пожар.

### Логические блоки

- **AND** — выдаёт сигнал, если активны все входы.
- **OR** — выдаёт сигнал, если активен хотя бы один вход.
- **XOR** — выдаёт сигнал, если активен только один вход.
- **NAND** — обратный вариант AND.
- **NOR** — обратный вариант OR.
- **XNOR** — обратный вариант XOR.
- **Разветвитель** — копирует один сигнал на несколько выходов.
- **Логический преобразователь** — переводит обычный сигнал в число и обратно.

### Функциональные блоки

- **Выключатель** — выключатель с управлением через сигналы.
- **Переключатель** — переключает питание между двумя выходами.
- **Математический блок** — выполняет математические операции и сравнения над числовыми значениями.
- **Мультитул** — универсальный блок с несколькими режимами: подсчёт предметов, пешек или урожая, управление дверями и приборами, проверка заполненности складов.

### Генераторы, память и вывод

- **Диод** — пропускает питание только в одну сторону.
- **Генератор сигнала** — постоянный источник сигнала.
- **Генератор тика** — периодический импульс.
- **Регистр** — переключает состояние по входному сигналу.
- **Таймер** — задерживает сигнал.
- **Память** — хранит числовое значение.
- **Экран** — показывает цифру; несколько экранов можно использовать для вывода числа.
- **Часы** — выдают сигнал в заданное время суток.
- **Рупор** — отправляет уведомление с заданным игроком текстом по любому сигналу.

### Производство

- **Блок-ремесленник** — встаёт на рабочее место у верстака вместо колониста и выполняет его очередь заданий. Работает медленнее живого мастера, зато не спит и не отвлекается.

## Примеры использования

- Включать или отключать питание по условию.
- Строить схемы с несколькими датчиками и логическими условиями.
- Разделять участки электросети через диоды.
- Выводить числовые значения на экраны.
- Реагировать на движение, температуру, освещение, запас энергии, огонь или загрязнение.

## Установка

Установите мод через Steam Workshop или вручную поместите папку RimLogic в `RimWorld/Mods`.

Harmony должен загружаться раньше RimLogic.

## Совместимость

- RimWorld 1.6
- Требуется Harmony
- Можно добавлять в существующее сохранение
- Поддерживаются русский и английский языки
- Мультиплеер не поддерживается
